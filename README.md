# VOID Browser

مرورگر VOID — مرورگر تحت دسکتاپ با دستیار هوش مصنوعی لوکال، دانلود ویدیو و دوبله فارسی خودکار.

## 📦 برای دادن پروژه به دیگران (روش پیشنهادی)

فایل **`VOID Browser Setup.exe`** (داخل پوشه `dist` بعد از بیلد) را به هر کسی بدهید.

نصب‌کننده فقط حدود **۸۰ مگابایت** است و در **اولین اجرای برنامه**، خودش به صورت خودکار این‌ها را دانلود می‌کند:

| ابزار | حجم تقریبی | کاربرد |
|---|---|---|
| ffmpeg + ffprobe | ~110 MB | پردازش ویدیو و صدا |
| yt-dlp | ~22 MB | دانلود از یوتیوب |
| whisper.cpp | ~9 MB | تشخیص گفتار |
| مدل whisper (q5_1) | ~181 MB | دقت تشخیص گفتار |

مقصد دانلود: `%APPDATA%\void-browser\tools` — فقط یک بار انجام می‌شود.

نکته‌ها برای کاربر گیرنده:
- اینترنت در اولین اجرا لازم است (اگر GitHub/HuggingFace در دسترس نبود به VPN نیاز دارد)
- برای **دوبله ویدیو** سرور Ollama هم لازم است: از [ollama.com](https://ollama.com) نصب کنید و بعد در CMD بزنید: `ollama pull qwen2.5:3b`

## 🛠 برای توسعه

```
npm install
npm start
```

ابزارها (ffmpeg.exe، yt-dlp.exe، پوشه whisper_resources) را کنار فایل‌های پروژه بگذارید تا دوباره دانلود نشوند — در غیر این صورت برنامه در اولین اجرا خودش آنها را دانلود می‌کند.

## ساخت فایل نصب

```
npm run build
```

خروجی: `dist\VOID Browser Setup 1.0.0.exe`

## ساختار اصلی

| فایل | توضیح |
|---|---|
| `main.js` | منطق اصلی Electron، IPC، مسیریابی ابزارها، دانلود خودکار |
| `dub-pipeline.js` | خط لوله دوبله (تشخیص گفتار ← ترجمه با Ollama ← TTS ← میکس) |
| `tools-setup.js` | ماژول دانلود خودکار ابزارهای خارجی |
| `index.html` | رابط کاربری کامل مرورگر |
| `setup-tools.ps1` | اسکریپت دستی راه‌اندازی برای توسعه‌دهنده‌ها (اختیاری) |
